# DA-004 — DairyOS Herd Data Model Architecture

**Document ID:** DA-004
**Version:** 1.0
**Status:** Approved Baseline

---

# 1. Purpose

Defines herd structure and management data architecture.

---

# 2. Herd Data Model Vision

DairyOS shall represent herd composition, movement, and performance.

---

# 3. Core Herd Data Entities

## Herd Structure

Contains:

- Groups
- Pens
- Animal membership

---

## Herd Status

Contains:

- Active animals
- Dry animals
- Replacement animals

---

## Herd Performance

Contains:

- Production indicators
- Population metrics

---

# 4. Data Relationships

Herd data shall connect with animal, production, and health domains.
