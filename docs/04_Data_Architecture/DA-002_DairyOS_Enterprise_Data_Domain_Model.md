# DA-002 — DairyOS Enterprise Data Domain Model

**Document ID:** DA-002
**Version:** 1.0
**Status:** Approved Baseline

---

# 1. Purpose

Defines enterprise-level data domains within DairyOS.

---

# 2. Enterprise Data Domains

## Master Data Domain

Contains:

- Animals
- Suppliers
- Staff
- Farm configuration

---

## Operational Data Domain

Contains:

- Tasks
- Activities
- Events

---

## Biological Data Domain

Contains:

- Health
- Reproduction
- Production

---

## Business Data Domain

Contains:

- Finance
- Inventory
- Procurement

---

# 3. Domain Data Ownership

Each domain shall maintain responsibility for its own data integrity.
