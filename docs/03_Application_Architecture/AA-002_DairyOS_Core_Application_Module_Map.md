# AA-002 — DairyOS Core Application Module Map

**Document ID:** AA-002
**Version:** 1.0
**Status:** Approved Baseline

# 1. Purpose

Defines the major application modules within DairyOS.

---

# 2. Core Application Modules

## Farm Operations Module

Provides:

- Daily workflows
- Tasks
- Operational monitoring

---

## Herd Management Module

Provides:

- Animal records
- Lifecycle management

---

## Animal Health Module

Provides:

- Health tracking
- Treatment workflows

---

## Production Module

Provides:

- Milk recording
- Performance monitoring

---

## Business Management Module

Provides:

- Finance
- Inventory
- Procurement

---

## Intelligence Module

Provides:

- Analytics
- Decision support

---

# 3. Module Architecture Principle

Each module owns its business responsibility while participating in the DairyOS platform.
